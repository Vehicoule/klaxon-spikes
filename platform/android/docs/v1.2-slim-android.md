## Deux breaks réels trouvés et corrigés (documentés, pas d'artifice)

1. **Link** : `SDL_android.c` référence `HIDDeviceManager_tab` sans garde
   (upstream ne teste pas Android + `SDL_HIDAPI=OFF`) → patch vendored
   `#ifndef SDL_HIDAPI_DISABLED` (include + register_methods).
   `sdl-android-hidapi-guard.patch`.
2. **Runtime** : `SDLActivity.onCreate` → `HIDDeviceManager.acquire()` →
   `UnsatisfiedLinkError` fatal → stub try/catch + null (usages déjà
   null-guardés). Diff canonique SDLActivity.java.
